Milez Ahead · Platform

One platform, three ways in, one set of rules.

A control room, a driver app, and WhatsApp for members — all speaking to a single secure database that decides who can see what. Built on standard, portable, enterprise-grade parts.

PostgreSQL 17 Flutter · iOS + Android React · TypeScript WhatsApp · Meta Cloud API Multi-tenant
01

The stack, layer by layer

The spine

Security lives in the database, not the app

Every table is governed by row-level security, and the business logic — pricing, credit balances, driver payouts, allocation — runs as functions inside the database. An insurer can only ever read their own trips; a driver only their own jobs. All three apps get the same answer, and none of them can bypass the rules. Access control isn't something a screen decides.

Database

Managed PostgreSQLPostgres 17 · Supabase

A full, standard Postgres database on enterprise infrastructure. Nothing proprietary locked inside — the schema and logic are portable SQL.

Control room

Dispatch consoleReact · TypeScript · Cloudflare

Where the team allocates drivers, tracks trips live and manages members. Served on Cloudflare and gated behind Cloudflare Access.

Driver

Native driver appFlutter · iOS + Android

One codebase, native on both platforms. Drivers sign in with their cell number and a one-time SMS PIN — no passwords to leak or reset.

Member

WhatsApp channelMeta Cloud API · 360dialog

Members book, get driver details and live tracking, and rate their trip — all in WhatsApp, on approved message templates.

Logic

Serverless functionsDeno · TypeScript

Anything that must not run on a phone — sending messages, payment links, allocation — runs server-side, close to the database.

Delivery

Automated releasesGitHub Actions · CI/CD

Console, database changes and functions all deploy on merge. Every change is reviewed and traceable to a single commit.

04

Built to grow

Multi-tenant

One platform, many partners

Each insurer or partner program carries its own rate card, branding and reporting — all off the same shared infrastructure.

Accountability

Every trip has a paper trail

An append-only audit history on each trip records who changed what, and when. Nothing edited quietly disappears.

Portable

Nothing locked in a black box

Schema, logic and security policies are all versioned SQL in source control — the whole system is rebuildable from code.
